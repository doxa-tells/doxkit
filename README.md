# DoxKit

Приложение для Mac и Windows: сжатие, смена формата, расшифровка речи в текст (Whisper), минус из песни (убрать голос нейросетью BS-RoFormer) и скачивание видео по ссылке (YouTube, TikTok, Instagram…). Всё работает на вашем компьютере.

## Установка на Mac

Откройте **Терминал** (Cmd+Пробел → «Терминал»), вставьте и нажмите Enter:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/doxa-tells/doxkit/main/install.sh)"
```

Если попросит пароль — это пароль от Mac (символы при вводе не видны).

## Установка на Windows 10/11

Нажмите **Пуск**, наберите **PowerShell**, откройте, вставьте и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/doxa-tells/doxkit/main/install.ps1 | iex
```

Windows несколько раз спросит «Разрешить изменения?» — нажимайте «Да».

## Общее

- Установка 10–20 минут, скачается ~3 ГБ.
- В конце на рабочем столе появится ярлык **DoxKit**.
- Обновление — та же команда.
- Готовые файлы — в папке «Загрузки/DoxKit».
- Расшифровка быстрее всего на Mac с чипом M1–M4. На Windows и Intel-Mac она идёт на процессоре: час записи ≈ 15–40 минут в зависимости от компьютера.
