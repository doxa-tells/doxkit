# DoxKit

Приложение для Mac: сжатие, смена формата, расшифровка речи в текст (Whisper) и скачивание видео по ссылке (YouTube, TikTok, Instagram…). Всё работает на вашем компьютере.

## Установка — одна команда

Откройте **Терминал** (Cmd+Пробел → «Терминал»), вставьте и нажмите Enter:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/doxa-tells/doxkit/main/install.sh)"
```

- Займёт 10–20 минут (скачается ~3 ГБ: ffmpeg, LibreOffice, модель Whisper).
- Если попросит пароль — это пароль от вашего Mac. При вводе символы не видны, это нормально.
- В конце на рабочем столе появится иконка **DoxKit**.

Обновление — та же команда.

## Требования

- macOS 13 и новее
- Расшифровка в текст — только Mac с чипом M1/M2/M3/M4. На Intel работает всё остальное.

## Где результаты

Папка `Загрузки/DoxKit`.
